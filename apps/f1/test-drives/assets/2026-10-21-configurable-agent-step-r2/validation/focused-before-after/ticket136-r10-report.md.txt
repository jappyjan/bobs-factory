Fix: one generator evaluator shared by synchronous compatibility and asynchronous runtime APIs. Every condition retains the independent 100,000-AST-visit limit. A separate total 1,000,000-work-unit budget pays for pointer segments, collection visits/expansions, lookup comparisons, operands, object properties, canonical tokens and characters, encoding/joining, hashing/membership, sorting comparisons, and text scans. Whole-graph JSON.stringify canonicalization is removed. Native sort is prepaid by maximum comparator calls and key characters, and counts actual calls; string quoting is prepaid for worst-case escaping. Fixed format callbacks prepay node-count times the complete charged argument footprint (including all key/string characters), so repeated pairwise refinement/string comparisons cannot hide behind one AST visit. Format callbacks remain trusted fixed library parsers, not recipe scripts.

Rule data has 48-level depth and 20,000-element collection/selection limits; canonical strings and configuration literal/key characters are capped at 1,000,000. Existing condition nesting12, rule count50 and configuration nodes10,000 remain. Async evaluation uses setImmediate checkpoints after2,048 charged work units and yields before starting, checks AbortSignal, closes its generator on cancellation, and propagates abort unchanged. Limits reject output and retain existing OutputValidationError correction. Sync read predicates inspect selected context only, preserving intentional lazy host getters.
