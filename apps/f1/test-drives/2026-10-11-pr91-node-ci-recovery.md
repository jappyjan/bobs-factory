# PR91 Node CI: compiled MCP recovery and shared build isolation

Date: 2026-10-11. Starting commit: `482e95cbaed55be6e4f01916b0095c77979d2fdc`.
Change: only the `test` and `test:run` commands in `apps/desktop/package.json`
stop rebuilding shared core output during concurrent tests. Existing general CI
and desktop CI build prerequisites before testing. Standalone desktop tests also
require the workspace dependencies to be built first.

## Diagnosis

Actual [Node CI run 38135979972](https://github.com/jappyjan/bobs-factory/actions/runs/38135979972),
job `114459812711`, used Node `22.23.3`. It failed the existing
`factory-operator-recovery.f1.test.ts` at EdgeWorker construction:
`TypeError: createLogger is not a function`, `EdgeWorker.ts:553`, test line 82.
MCP tools had 1 failed / 12 passed files and 1 failed / 71 passed tests.
The Node 24.x job was cancelled by fail-fast; that is not a test result.

The logs show `apps/desktop test:run` invoking a second core `tsgo` build while
recursive MCP tests import compiled core exports. Those generated files are
rewritten in place. The isolated Node 22 test, its package suite and an ordinary
parallel desktop/MCP run all passed locally before the fix, consistent with a
timing-dependent read of partially written output rather than a missing source
export or a logger mock.

A controlled reproduction temporarily held the isolated checkout's generated
`packages/core/dist/logging/index.js` at its first export (LogLevel), then ran
the unmodified recovery test on Node 22.23.3. It reproduced the exact TypeError
and both source locations. The original generated bytes were restored in a
`finally` block. This proves the partial-output failure mechanism; the hosted
log does not record the individual filesystem read/write timing.

The fix removes the overlapping writer instead of mocking the product logger,
changing imports or weakening recovery assertions. No new implementation-text
test was added: the existing end-to-end recovery test covers the failure and
the direct output inspection verifies the test commands no longer rewrite core.

## Relevant F1 validation

F1 applies to the affected compiled operator recovery harness. Both local runs
used the existing deterministic mocked-agent scenario with a temporary home,
Git repository and bare upstream, an embedded real EdgeWorker/RPC server, and
the compiled CLI operator MCP entry point over a real stdio client transport.
No model CLI, inference API or real Taskbot endpoint was called.

The unchanged assertions cover missing transport, exact configuration revision
and permissions, authentication failures and redaction, retry safeguards,
configuration persistence/hot reload, completed workflow output, tools/list,
and preservation of the accepted OpenCode runner without a native Codex call.
