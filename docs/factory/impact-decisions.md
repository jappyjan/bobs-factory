# Impact and convergence in recipes

Impact assessment is authored agent output. Review and QA recipes select scoped
reads and `revisionScope` paths, then the generic engine checks receipt freshness
before reuse. There is no runtime impact-decision contract or tool.

See [the composition contract](factory-recipe-contract.md),
[reuse and freshness](nodes.md#receipts-and-freshness) and
[Converge](node-catalog.md#converge). Recipe branches route stalled work to Display
for human direction without granting approval or bypassing checks.
