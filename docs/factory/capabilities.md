# Factory capability reference

The runtime executes registered nodes, lexical graphs and durable receipts.
Factory and Takeover compose planning, independent review, QA, CI, human
approval, merge and external delivery as ordinary recipes. Improve uses generic
research, Display, Snapshot, For each, File issues and Launch runs nodes. Simple
keeps the native conversation lifecycle without a graph.

- Agents consume declared reads, return validated data and optionally resume
  their own native conversations. They do not choose a screen or authorize effects.
- Display renders bounded inert components and owns explicit human submissions,
  item discussions, exact content digests and notification opt-in.
- Check, Transform and Converge evaluate data; recipe branches own all domain
  decisions and correction loops.
- Calls, Parallel and For each isolate lexical output/receipt scope. Declared
  ports carry producer provenance; arbitrary JSON cannot become approval evidence.
- Git, PR, CI, Merge, Ticket, Exec, File issues and Launch runs use configured
  integrations and durable effect reconciliation. Capability metadata grants no
  credentials or permission. Existing identity/tool profiles and native credential
  stores remain authoritative.
- Reuse, scoped revisions, bindings and fresh rules preserve original evidence.
  Merge verifies the approved provider head separately from local freshness.
- Machine capacity, shared resource reservations, visit budgets, progress budgets,
  cancellation and update draining remain independent generic safeguards.
- Old graphs and local forks are retained read-only. Restart from the current
  bundled recipe; old receipts and native conversations are never rewritten into
  new execution. Graphless Simple sessions remain resumable.
