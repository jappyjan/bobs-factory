# External delivery

The nodes-v1 `v2-external` recipe plans changes against verified ticket identities,
reads the before-state, applies operations through generic Ticket nodes and
independently verifies the result. Display binds the actual evidence for explicit
human acceptance. Mixed work carries the original approval and confirmed merge
producer into external delivery. Only final external acceptance completes a mixed
ticket. Rejected or changed work returns through recipe-owned revision routes.

`v2-deferred` retains planning-only restrictions; discussion of scope does not
authorize implementation. There are no external-recovery HTTP actions or runtime
delivery-contract fields. Restart historical runs with the current recipe.
