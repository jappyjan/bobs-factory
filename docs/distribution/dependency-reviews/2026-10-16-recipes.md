# Recipes dependency source review

Reviewed by Codex release work on 2026-10-16, independently of the Recipes
implementation. Source delta: accepted baseline `84433882` to merged Recipes
commit `9bd50568`. The exact machine-readable review is
[`recipe-workbench.json`](../../../distribution/dependency-reviews/recipe-workbench.json).

The 22 added lockfile packages were downloaded from the official npm registry.
Each complete archive matched the lockfile's SHA-512 and the retained SHA-256 and
byte size. Archives total 1,106,333 bytes. Package names/versions, package.json
bytes and complete license texts were checked without extracting or executing
package code. All archive entries are regular files/directories; no native
binary or installation hooks were found. Retained package pins and metadata did
not change. Direct additions are `@dagrejs/dagre` and `@xyflow/react` in the
edge-worker's development dependencies; the review enumerates their complete
new closure, including type packages. The prior WebAuthn removals remain covered
by the retained baseline source superset.

Upstream declarations and full notices use MIT, ISC and BSD-3-Clause. The full
permission, copyright and disclaimer text is retained in the reviewed archives.
This is a distribution input/source review, not a legal opinion. Bun/Electron,
native object and relink observations retain their accepted historical identity.
No new native relink or human per-candidate approval is claimed.

The web build measured 145 browser, service-worker and CSS package inputs. The
binary smoke build contains full notice entries for all 145. One existing
package, `react-remove-scroll-bar@2.3.8`, omits its license file from its npm
archive. Its registry declaration is MIT. Its reported npm gitHead is unavailable
upstream; no correspondence to that unavailable commit is claimed. The complete
[upstream MIT notice](https://github.com/theKashey/react-remove-scroll-bar/blob/7301c160fda44cb8cf2b9fdfde61efad35736196/LICENSE)
is pinned to the actual source revision that added it, inventoried in the review,
and included in the new binary and source material.

Verification:

- Workspace dependency installation from the frozen lockfile and package build
  passed; `pnpm audit` reports no known vulnerabilities.
- Source policy verifies all 103 protected inputs and retains 23 fresh source/
  notice materials: 22 npm archives plus the separately pinned upstream notice.

  returned `1.0.0-beta`; no production runtime was replaced by this smoke check.
